# Jatre Namma Pride

## 📌 Project Overview
Jatre Namma Pride is an Android application developed to showcase the culture, traditions, festivals, tourism, and pride of Karnataka. The application helps users explore famous places, local events, food culture, and heritage information in an easy and interactive way.

This project is developed using modern Android App Development concepts with the support of Generative AI tools.

---

## 🎯 Objectives
- To promote Karnataka culture and tourism
- To provide information about famous festivals and traditions
- To create a user-friendly mobile application
- To improve digital accessibility for users
- To learn Android development using Gen AI technologies

---

## ❗ Problem Statement
Many people are unaware of Karnataka’s rich cultural heritage, famous festivals, and tourist attractions. There is a need for a simple mobile application that provides complete information in one place with an attractive and easy-to-use interface.
